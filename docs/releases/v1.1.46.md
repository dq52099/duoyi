# v1.1.46

本版本是自 v1.1.43 以来围绕品牌视觉、桌面与移动端样式、日历黄历、性能流畅度、系统通知与桌面小组件的全面升级版本。正式安装包仍由 GitHub Actions 使用既有 release keystore 构建与签名。

## 更新亮点

- **品牌视觉与 Web 启动体验**：统一对齐 iOS System Blue（`#0066D6` / `#0A84FF`）主色调，焕新应用图标与 Web Favicon，并修复移动端 Chrome 切后台恢复黑屏问题。
- **黄历与日历全面升级**：补齐 2024–2027 年法定节假日与调休安排，修复神煞计算与闰月选择器，新增黄历工具箱与桌面端黄历/日历/今日视图；同步增强 Web 文件下载、笔记、全局搜索与倒数日体验。
- **性能与卡顿治理**：桌面 Web 去除可滚动区域的 `BackdropFilter`，离屏页面通过 `TickerMode` 暂停动画，命令面板增加防抖与缓存记忆；秒表与番茄钟每秒刷新局部隔离；为农历、节假日、报告、洞察与图片解码引入 LRU 缓存，并将耗时编码迁移至 `compute()` 后台 Isolate。
- **通知与提醒系统重构**：补齐课程表、日程与番茄钟后台结束提醒，支持勿扰时段、10/15/60 分钟延后（保留原标题与正文）及习惯推送直接打卡；限制 380 个系统闹钟配额上限，加固 Android 12–16 时区/精确闹钟/后台启动（BAL）原生链路，并完善 iOS `UNUserNotificationCenterDelegate` 与通知分类交互。
- **桌面小组件美化与交互升级**：适配 iOS System Blue 与纯正暗黑模式，新增目标/习惯/专注进度条与专注暂停/继续/结束按钮；Android 小组件支持后台静默操作；日历小组件集成农历节假日摘要与按日期跳转；整合倒数日展示，提供单组件配置界面及应用内真实数据/暗黑模式实时预览。
- **全端 Light / Dark / Glass 样式与国际化打磨**：系统性重塑核心设计系统、桌面端工作台与移动端页面排版、对比度、阴影层次及全量中英文文案边界隔离。
