# v1.1.47

本版本在完整继承 v1.1.46 全部功能与视觉升级的基础上，彻底修复 Android 分包覆盖升级时的 `INSTALL_FAILED_VERSION_DOWNGRADE` 版本降级报错。签名配置保持不变，正式 Release 仍由 GitHub Actions 使用既有 release keystore 构建。

## 修复：Android 覆盖升级兼容性

- **修复 `INSTALL_FAILED_VERSION_DOWNGRADE` 报错**：此前 Flutter `--split-per-abi` 默认按 `abiCode * 1000 + versionCode` 计算版本号，导致历史 ABI 分包（如 `v1.1.43-arm64-v8a.apk` 的 `142009`、`v1.1.46-arm64-v8a.apk` 的 `142012` 等）高于通用包与常规递增版本号（`140012`），从而在覆盖安装通用包或新版本时触发版本降级拒绝。
- **统一版本号序列与 `+10` 发布步进**：将基础构建号提升至 `1500000`（后续版本统一按 `+10` 步进：`1500010`、`1500020`……），并调整打包低位偏移为 `universal (+9) > x86_64 (+4) > arm64-v8a (+2) > armeabi-v7a (+1)`（AAB 保持基础值 `1500000`），全部产物均严格高于历史最高构建号 `144012`。
- **全路径无缝覆盖升级**：无论设备此前安装的是 `v1.1.43` / `v1.1.46` 的 `arm64-v8a`、`armeabi-v7a`、`x86_64` 分包还是通用包，均可直接平滑覆盖安装 `duoyi-v1.1.47-arm64-v8a.apk`（`1500002`）或通用包 `duoyi-v1.1.47.apk`（`1500009`），跨包及同版本分包升通用包均无需卸载重装。

## 更新亮点（完整继承自 v1.1.46）

- **iOS System Blue 视觉与暗黑模式重塑**：主色调统一对齐 iOS System Blue（`#0066D6` / `#0A84FF`），焕新应用图标与 Web Favicon，系统性打磨全端 Light / Dark / Glass 样式、排版、对比度、阴影层次及全量中英文文案边界隔离，并修复移动端 Chrome 切后台恢复黑屏问题。
- **黄历与日历全面升级**：补齐 2024–2027 年法定节假日与调休安排，修复神煞计算与闰月选择器，新增黄历工具箱与桌面端黄历/日历/今日视图；同步增强 Web 文件下载、笔记、全局搜索与倒数日体验。
- **性能、滚动、计时与缓存优化**：桌面 Web 去除可滚动区域的 `BackdropFilter`，离屏页面通过 `TickerMode` 暂停动画，命令面板增加防抖与缓存记忆；秒表与番茄钟每秒刷新局部隔离；为农历、节假日、报告、洞察与图片解码引入 LRU 缓存，并将耗时编码迁移至 `compute()` 后台 Isolate。
- **通知与提醒系统重构**：补齐课程表、日程与番茄钟后台结束提醒，支持勿扰时段、10/15/60 分钟延后（保留原标题与正文）及习惯推送直接打卡；限制 380 个系统闹钟配额上限，加固 Android 14–16（含 12–16）时区/精确闹钟/后台启动（BAL）原生链路，并完善 iOS `UNUserNotificationCenterDelegate` 与通知分类交互。
- **桌面小组件美化与交互升级**：适配 iOS System Blue 与纯正暗黑模式，新增目标/习惯/专注进度条与专注暂停/继续/结束按钮；Android 小组件支持后台静默操作；日历小组件集成农历节假日摘要与按日期跳转；整合倒数日展示，提供单组件配置界面及应用内真实数据/暗黑模式实时预览。
