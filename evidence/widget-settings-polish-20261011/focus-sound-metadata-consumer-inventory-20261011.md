## Catalog contract

- `FocusSoundTrack` and `FocusSoundOption` keep Chinese-authored `label` metadata and optional `englishLabel`. Their `.label` getters follow `I18n.current`; `displayLabel(locale:)` accepts an explicit locale. When an authored entry omits `englishLabel`, it deliberately falls back to `label` ([focus_sound_catalog.dart](../../lib/core/focus_sound_catalog.dart:3)).
- The current catalog has 28 built-in tracks and 29 options (`none` plus one option per track). Each published entry has an English label. Labels are independent of stable IDs and asset paths ([focus_sound_catalog.dart](../../lib/core/focus_sound_catalog.dart:50), [focus_sound_catalog.dart](../../lib/core/focus_sound_catalog.dart:226), [focus_sound_catalog.dart](../../lib/core/focus_sound_catalog.dart:407)).
- `labelFor` resolves an option or one-track fallback and returns the localized `none` option for unknown IDs and unsupported mixes. Playback normalization is separate: built-in legacy noise IDs map to `night_rain`, unknown built-in IDs map to `none`, and `trackIdsFor`/`assetsFor` reject `+` mix IDs. Published options are single-track only. Pomodoro model/provider paths special-case `custom:` IDs before using this built-in normalizer ([focus_sound_catalog.dart](../../lib/core/focus_sound_catalog.dart:438), [focus_sound_catalog.dart](../../lib/core/focus_sound_catalog.dart:442), [focus_sound_catalog.dart](../../lib/core/focus_sound_catalog.dart:452), [focus_sound_catalog.dart](../../lib/core/focus_sound_catalog.dart:475), [pomodoro.dart](../../lib/models/pomodoro.dart:411)).
- `FocusSoundService` uses IDs and asset paths for playback. Custom IDs resolve through a separate ID-to-file-path map; neither playback nor asset selection consumes display labels ([focus_sound_service.dart](../../lib/services/focus_sound_service.dart:66), [focus_sound_service.dart](../../lib/services/focus_sound_service.dart:130)).

## Persistence, backup, and sync

- **Built-in labels are presentation metadata.** `PomodoroConfig` and `PomodoroSession` serialize `whiteNoiseSound` IDs, not labels. Their readers normalize built-in values while preserving `custom:` IDs. `PomodoroProvider.setWhiteNoiseSound` follows the same split ([pomodoro.dart](../../lib/models/pomodoro.dart:56), [pomodoro.dart](../../lib/models/pomodoro.dart:74), [pomodoro.dart](../../lib/models/pomodoro.dart:315), [pomodoro.dart](../../lib/models/pomodoro.dart:328), [pomodoro.dart](../../lib/models/pomodoro.dart:411), [pomodoro_provider.dart](../../lib/providers/pomodoro_provider.dart:1329)).
- **Goal/todo focus links keep the selected ID.** `FocusLink.toJson/fromJson` reads and writes `whiteNoise` verbatim, and is embedded in both goal and todo JSON. These paths do not persist a built-in display label or normalize the ID ([goal.dart](../../lib/models/goal.dart:453), [goal.dart](../../lib/models/goal.dart:482), [goal.dart](../../lib/models/goal.dart:489), [todo.dart](../../lib/models/todo.dart:253), [todo.dart](../../lib/models/todo.dart:334)).
- Local keys are `pomodoro_config`, `pomodoro_sessions`, `duoyi_goals`, and `todos`; the records serialize the model IDs above ([pomodoro_provider.dart](../../lib/providers/pomodoro_provider.dart:175), [pomodoro_provider.dart](../../lib/providers/pomodoro_provider.dart:313), [pomodoro_provider.dart](../../lib/providers/pomodoro_provider.dart:321), [goal_provider.dart](../../lib/providers/goal_provider.dart:68), [todo_provider.dart](../../lib/providers/todo_provider.dart:478), [todo_provider.dart](../../lib/providers/todo_provider.dart:627)).
- Cloud sync maps Pomodoro config/sessions, goals, and todos into their corresponding collections. The mappings do not include `duoyi_custom_focus_sounds` ([cloud_sync_provider.dart](../../lib/providers/cloud_sync_provider.dart:1050), [cloud_sync_provider.dart](../../lib/providers/cloud_sync_provider.dart:1058), [cloud_sync_provider.dart](../../lib/providers/cloud_sync_provider.dart:1074)). Thus model records can carry a `custom:` selection while the custom sound metadata/file is absent on another device.
- Backup `exportAll` includes the `duoyi_custom_focus_sounds` preference key and serializes SharedPreferences values; the custom sound metadata therefore includes `{id, label, path, importedAt}`. The audio files themselves live under the app documents `custom_focus_sounds` directory and are not copied by this preference export ([backup_service.dart](../../lib/services/backup_service.dart:128), [backup_service.dart](../../lib/services/backup_service.dart:170), [custom_focus_sound_provider.dart](../../lib/providers/custom_focus_sound_provider.dart:24), [custom_focus_sound_provider.dart](../../lib/providers/custom_focus_sound_provider.dart:148)). Account cleanup removes both the preference key and that directory ([account_local_data_cleaner.dart](../../lib/services/account_local_data_cleaner.dart:63), [account_local_data_cleaner.dart](../../lib/services/account_local_data_cleaner.dart:181)). A restored custom-sound record can consequently retain a path whose file was not transferred.
- Pomodoro completion and session edits write a TimeAudit note as `白噪音：<raw sound ID>`; this is a persisted user-facing ID string, not the localized catalog label ([pomodoro_provider.dart](../../lib/providers/pomodoro_provider.dart:701), [pomodoro_provider.dart](../../lib/providers/pomodoro_provider.dart:1015)).

## Custom sound labels

- Custom sound metadata is persisted under `duoyi_custom_focus_sounds` as a string list of JSON objects containing `id`, `label`, `path`, and `importedAt` ([custom_focus_sound_provider.dart](../../lib/providers/custom_focus_sound_provider.dart:11), [custom_focus_sound_provider.dart](../../lib/providers/custom_focus_sound_provider.dart:43), [custom_focus_sound_provider.dart](../../lib/providers/custom_focus_sound_provider.dart:155)).
- Import derives the label from the selected filename’s basename, strips the extension, and trims whitespace. It preserves the authored filename text verbatim, including Chinese or English; it is not translated when the interface locale changes. Blank names and missing metadata use the Chinese literal `自定义音频` ([custom_focus_sound_provider.dart](../../lib/providers/custom_focus_sound_provider.dart:117), [custom_focus_sound_provider.dart](../../lib/providers/custom_focus_sound_provider.dart:178), [custom_focus_sound_provider.dart](../../lib/providers/custom_focus_sound_provider.dart:55)).
- Imported files are copied into app documents and registered for playback under generated `custom:<microseconds>` IDs. Removing a custom sound deletes its file and metadata entry ([custom_focus_sound_provider.dart](../../lib/providers/custom_focus_sound_provider.dart:111), [custom_focus_sound_provider.dart](../../lib/providers/custom_focus_sound_provider.dart:131), [custom_focus_sound_provider.dart](../../lib/providers/custom_focus_sound_provider.dart:163)).
